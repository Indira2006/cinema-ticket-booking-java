# Cinema Ticket Booking System (Console-Based)

A menu-driven Java console application for booking cinema tickets.

## Features
- Select movie category, movie and show time
- View seat layout with available/booked status
- Book multiple seats and prevent double booking
- Generate booking receipt with total amount

## Technologies
Java, Arrays, Scanner

## How to run
1. Open CinemaTicket.java in Eclipse
2. Run as Java Application
3. Follow the menu options in the console
